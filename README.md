# PulseScribe Releases

This public repository hosts PulseScribe desktop installers and release notes.
It is for downloads only and does not contain the application source code.

Download the latest release:

- Windows x64: `PulseScribe-portable-win-x64.exe`
- macOS Intel: `PulseScribe-mac-x64.dmg`
- macOS Apple Silicon: `PulseScribe-mac-arm64.dmg`

Visit [PulseScribe](https://pulsescribe.app) for product information.
